# Claude Code and Codex

Claude Code and Codex are preinstalled command-line tools in the approved
Coder workspace. They can read project files, edit code, and run commands.

Open a workspace terminal in your project directory and start one tool:

| Tool | Command | Usage documentation |
| --- | --- | --- |
| Claude Code | `claude` | [Claude Code quickstart](https://code.claude.com/docs/en/quickstart) |
| Codex | `codex` | [Codex CLI](https://developers.openai.com/codex/cli) |

Follow the tool's sign-in prompts with an approved account. Tool sign-in is
separate from GSEL sign-in. Use the provider's documented remote sign-in
method if the browser cannot complete authentication from your workspace.

Ask the tool to use the project's Pixi environment and tasks. Review its
changes and check the results before committing. Submit research experiments
through [Gateway](../compute/experiments.md).

Follow the [compute-use rules](../compute/rules.md) when sharing material
with an AI service or allowing a tool to run commands.
