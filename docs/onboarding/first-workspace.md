# First Coder workspace

After setting up your [GitHub account](github-account.md) and
[GSEL sign-in](gsel-sign-in.md):

1. [Create a personal workspace](../coder/create-workspace.md) from the
   approved template.
2. [Open it in your browser](../coder/open-in-browser.md), or connect with the
   [CLI](../coder/cli.md) or a [desktop editor over SSH](../coder/ssh.md).
3. [Set up a Pixi project](../projects/pixi.md).
4. Use [Claude Code or Codex](../coder/tools.md) in the workspace as needed.
5. [Submit experiments through Gateway](../compute/experiments.md).
