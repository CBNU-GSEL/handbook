# Glossary

**Coder workspace**
: A personal development environment opened through a browser, the Coder
CLI, or SSH.

**Template**
: A predefined Coder workspace configuration. Use the approved **Scratch**
template for research workspaces.

**Pixi**
: A tool for managing a project's dependencies, environments, and commands.
A Pixi workspace is a project directory inside your Coder workspace.

**`gsel-compute` Gateway**
: The service for submitting experiments and checking run status.

**Project**
: A registered research project with a repository and supported tasks.

**Experiment**
: A named research computation with a short summary and selected parameters.

**Run**
: One submitted execution, identified by its `run_id`.

**CPU threads**
: The CPU parallelism requested for a run.

**RAM**
: System memory used by the program and its data.

**VRAM**
: GPU memory used by data and computations on the GPU.

**GiB**
: A binary memory unit equal to 1,073,741,824 bytes.

**Smoke run**
: A short execution check using a small workload before a standard run.
